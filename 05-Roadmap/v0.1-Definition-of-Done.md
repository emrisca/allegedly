## 1. Binary Release Gate Policy (`v0.1-dev` vs. `v0.1.0` Unsigned Alpha Tag)

Allegedly enforces a **strict binary PASS / FAIL policy**. Soft waivers, undocumented exceptions, and silent threshold relaxation are prohibited. Any mandatory `v0.1.0` gate marked **`UNVERIFIED`** is treated as an automatic **`FAIL`** for `v0.1.0` tag promotion until the required CI harness or verification step produces reproducible evidence.

To prevent local development from stalling while keeping release quality uncompromised, `v0.1` separates two explicit gate tiers aligned to the canonical `v0.1` unsigned/ad-hoc Alpha scope in [[Milestones]] and [[Epics-and-Stories]]:

### 1.1 Tier A — Local Dev Alpha Slice (`v0.1-dev`) Gate (Runnable on macOS `arm64` Today)
Applies to every local vertical-slice sprint checkpoint and PR merge on Apple Silicon (`aarch64-apple-darwin`) with `CARGO_TARGET_DIR=/Users/abelmora/.cache/allegedly-target` and test scratch isolated under `/tmp/allegedly-*-test/`:
- **Required PASS:**
  1. All Layer 1 static invariants & unit/property suites (`cargo fmt --check`, `cargo clippy -D warnings`, `cargo test --release`, `vitest`, `tsc --noEmit`, zero-float `SV-08`, zero legacy prefix/extension lint).
  2. All Layer 2 local contract, fault-injection, OMS wire-mock, Risk-Reduction Bypass, SQLite WAL crash recovery, `keyring-rs` secret-leak, `cargo-deny v0.22.1`, and npm SPDX + exact `@ui-sdk` `"0.1.0-beta.17"` pin gates.
  3. All Layer 4 & Layer 5 macOS `arm64` micro-benchmarks and component/a11y tests (`S01` WebGL2 sync `0.000 CSS px`, `S04` Canvas2D `DOM Ladder` `60 fps` / `0` React commits, `S08` Dyadic VRVP `< 0.25 ms`, `FootprintSlabArena < 60 MiB` (`SV-13` Tier A), `ui-sdk` + `axe-core` a11y, `SV-02`–`SV-07`, `SV-10`, `SV-11` (`v0.1` honest `L2` non-MBO labeling + `[Est / Max]` PIQ badge), `SV-15`–`SV-19`).
  4. Zero live broker orders, zero real brokerage credentials, `allow-live-trading` feature OFF, `live_armed = false` at boot.
- **Explicitly Deferred to Tier B (Allowed `UNVERIFIED` during `v0.1-dev` only):** Cross-platform Windows `WebView2` (`x86_64-pc-windows-msvc`) and Intel macOS (`x86_64-apple-darwin`) CI runs, packaged unsigned/ad-hoc `.dmg`/`.msi`/NSIS installer size (`SV-20`), full OS process-tree packaged cold-start (`SV-01`/`SV-20`) & `< 300 MB` idle RAM (`SV-13` Tier B) harnesses, 30-minute unattended live soak, and macOS APFS `PRAGMA fullfsync = ON` batched Kill-Switch WAL hardware benchmark.

### 1.2 Tier B — `v0.1.0` Unsigned/Ad-Hoc Cross-Platform Alpha Tag Gate (Mandatory Before `v0.1.0` Tag)
Applies before cutting the **unsigned/ad-hoc cross-platform `v0.1.0` Alpha tag** (not publicly distributed or marketed; see §1.4 for signing, SBOM, and trademark gates deferred to `v0.2` / `v1.0` per [[Milestones]] and [[Epics-and-Stories]]). **100% of Tier A PLUS 100% of the following must transition from `UNVERIFIED` to `PASS`:**
1. **Cross-Platform Matrix Green (`[[Assumptions]]` `A01` — macOS + Windows First; Linux Deferred `Post-v1.0`):** `ci-pr-fast.yml`, `ci-bundle-mac-win.yml`, and `ci-nightly.yml` all green on **`macos-14` (`aarch64-apple-darwin`)**, **`x86_64-apple-darwin` (Intel macOS)**, and **`windows-latest` (`x86_64-pc-windows-msvc` + `WebView2` `embedBootstrapper`)** (`E01`, `E06`, `E10` · `ST-02`, `ST-25`, `ST-40`).
2. **Packaged Resource Budgets Empirically Measured (`SV-01`, `SV-13`, `SV-20`):** Unsigned/ad-hoc packaged macOS `.dmg`/`.app` and Windows `.msi`/NSIS `.exe` installer `< 40.0 MB`, packaged cold start `< 2.0 s` p95 with **`0` outbound DNS/TCP/UDP packets** (`updates.checkOnStartup = false`), and full OS process-tree idle RAM `< 300 MB` on both macOS (`WKWebView` + XPC helpers) and Windows (`WebView2` process tree) (`E01`, `E10` · `ST-03`, `ST-40`).
3. **Cross-OS Determinism & Hardware Durability (`SV-09`, `ADR-0009`):** Bit-exact cross-OS SHA-256 replay identity across macOS `arm64`, macOS `x86_64`, and Windows `x86_64` (`E04` · `ST-15`); macOS APFS `PRAGMA fullfsync = ON` batched 50-order Kill-Switch WAL benchmark passing (`<= 15 ms` target / `<= 25 ms` hard ceiling, `E09` · `ST-36`); dev-only `TA-Lib v0.8.3` (`BSD-3-Clause`) C oracle parity (`<= 1e-9`, `E08` · `ST-31`).
