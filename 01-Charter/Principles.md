# UX & Sovereignty Principles

> **Status:** Seeded in Phase 0. Owned by `ux-teardown` (`MV Orderflow & UX`), who will replace this seed with the full evidence-backed UX teardown principles and testable **Sovereignty Checklist** upon completing [[R10-UX-Teardown-Control-Model]].

## Seed Tenets (from [[Constraints]])
1. **Clarity without infantilization:** TradingView-grade visual hierarchy by default; MotiveWave-grade power one keystroke away.
2. **Settings-as-code:** Every visual, analytical, and hot-key preference serializes cleanly to diffable JSON/TOML with global → workspace → chart → study inheritance.
3. **Provenance is first-class UI:** Delayed feeds, inferred aggressor sides, and partial-venue volumes display unmistakable indicators — never hidden in footnotes.
4. **Keyboard-first, mouse-fluent:** Command palette + remappable keymaps + universal undo/redo.
5. **No account walls:** Zero features gated behind registration, cloud sync, or telemetry.
